# Network Canvas specifications

Public API and portable data-exchange specifications for Network Canvas, dedicated to the public domain under [CC0 1.0](LICENSE).

- [Template Registry API and exchange format, v1](template-registry/v1/README.md)
- [Source provenance](template-registry/v1/SOURCE.json)

The Registry specification is an initial implementation contract. Publishing it does not announce a deployed Registry service or qualify a Studio release. Template artifacts retain their own declared licenses.

Propose changes through issues and pull requests. Include the compatibility impact and the exact contract changes; changes to the normative OpenAPI contract originate in the [Network Canvas source repository](https://github.com/complexdatacollective/network-canvas-monorepo).
